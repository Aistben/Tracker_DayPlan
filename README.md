# Tracker_DayPlan

Трекер дня: планировщик задач + помидоро-таймер + статистика.
Десктопное приложение под Windows (Tauri 2 + React + TypeScript).

Концепт и мокапы — [`docs/CONCEPT.md`](docs/CONCEPT.md).

> Статус: **прототип**. Проверяется логика, не внешний вид.
> Стилизации намеренно нет — голый HTML.

## Что уже работает

- Задачи на день: добавить, удалить, переключить статус кликом по маркеру
- 6 статусов: `○` план · `◐` в работе · `●` выполнено · `◒` частично · `✕` отменено · `→` перенесено
- Навигация по дням, «закрыть день» с переносом незакрытого на завтра
- Таймер: помидоро с автозавершением или свободный секундомер
- Прерванные сессии записываются с флагом `completed: false` — время потрачено
- План/факт: `spent` считается из сессий, вручную не вводится
- Статистика: план/факт по дням недели, разбивка по категориям, активность по часам
- Данные в localStorage, при первом запуске — демо-история за неделю

## Запуск

```bash
npm install
npm run dev          # браузер, http://localhost:5173
npm run tauri dev    # десктоп-окно (нужен Rust)
```

## Сборка .exe

Собрать Windows-бинарник можно **только на Windows** — нужен Windows SDK и
WebView2. Из Linux/CI-контейнера не получится.

### Вариант 1: на своём ПК (проще всего)

Нужны [Node.js](https://nodejs.org) и [Rust](https://rustup.rs). Дальше:

```
build-exe.bat
```

Двойной клик по файлу. Первая сборка 5–10 минут (компилируется Rust),
последующие — секунды.

Результат:
- установщик — `src-tauri/target/release/bundle/nsis/*.exe`
- портативный exe — `src-tauri/target/release/Tracker DayPlan.exe`

Вручную то же самое: `npm install && npm run tauri build`

### Вариант 2: GitHub Actions

Workflow готов, но лежит в `ci/build-windows.yml`, а не в `.github/` — у агента
нет прав пушить workflow-файлы (GitHub блокирует это на уровне API). Включается
одной командой:

```bash
mkdir -p .github/workflows && cp ci/build-windows.yml .github/workflows/
git add .github && git commit -m "ci: сборка exe" && git push
```

После этого: вкладка **Actions** → **Build Windows exe** → артефакт
`TrackerDayPlan-windows`. Сборка идёт на windows-раннере GitHub, ставить ничего
не нужно.

### При первом запуске

Windows покажет синее окно SmartScreen «Защита Windows предотвратила запуск» —
exe не подписан сертификатом. Нажми **Подробнее → Всё равно выполнить**.
