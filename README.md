# Tracker_DayPlan

Трекер дня: планировщик задач + помидоро-таймер + статистика.
Веб-приложение на React + TypeScript + Vite.

Концепт и мокапы — [`docs/CONCEPT.md`](docs/CONCEPT.md).

> Статус: **прототип**. Проверяется логика, не внешний вид.
> Стилизации намеренно нет — голый HTML.

## Что работает

- Задачи на день: добавить, удалить, переключить статус кликом по маркеру
- 6 статусов: `○` план · `◐` в работе · `●` выполнено · `◒` частично · `✕` отменено · `→` перенесено
- Календарь по клику на дату: дни с работой подсвечены, точка = были сессии
- Правка задачи (двойной клик или ✏️), ручное время ±15 мин без таймера
- «Закрыть день» с переносом незакрытого на завтра
- Таймер: помидоро с автозавершением или свободный секундомер
- Прерванные сессии записываются с флагом `completed: false` — время потрачено
- План/факт: `spent` считается из сессий, вручную не вводится
- Статистика на главном экране: составной бар — каждая задача своим цветом,
  высота сегмента = потраченные часы; переключатель неделя / месяц / год
- Данные в localStorage, при первом запуске — демо-история за неделю

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка статики: `npm run build` → папка `dist/`, раздаётся любым хостингом
(GitHub Pages, Netlify, Vercel) или локально через `npm run preview`.

## Структура

```
src/
  lib/
    types.ts      доменная модель: Task, Session, Category, Settings
    storage.ts    слой хранения (localStorage) + демо-данные
    useStore.ts   состояние приложения и логика таймера
  screens/
    Today.tsx     главный экран: дата, таймер, задачи, статистика
    Stats.tsx     график часов по дням (встраивается в Today)
  App.tsx         корень
```

Хранение изолировано в `storage.ts` — при переезде на бэкенд или SQLite
меняется только этот файл.
