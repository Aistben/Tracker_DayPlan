# Tracker_DayPlan

Трекер дня: планировщик задач, помидоро-таймер и статистика на одном экране.
Веб-приложение на React + TypeScript + Vite.

Концепт и мокапы — [`docs/CONCEPT.md`](docs/CONCEPT.md).

> Статус: **рабочий прототип**. Логика и интерфейс готовы, данные хранятся
> локально в браузере.

## Идея

Не просто список дел, а связка **план → работа по таймеру → факт**.
Отмечаешь задачи, запускаешь таймер, видишь, куда реально ушёл день.
Ключевая метрика — не «сколько задач закрыл», а «сколько заложил и сколько
потратил».

## Возможности

### Задачи

- Добавление, удаление, правка названия и планового времени
  (двойной клик по названию или кнопка ✎, Enter — сохранить, Esc — отмена)
- Шесть статусов с цветными индикаторами: запланировано, в работе, выполнено,
  частично, отменено, перенесено
- Статус меняется автоматически кнопками таймера — вручную кликом не меняется
- Ручная корректировка времени ±15 мин, если работал без таймера
- У каждой задачи свой цвет: полоса слева, мини-шкала прогресса и сегмент
  на графике окрашены одинаково
- «Закрыть день» — незакрытые задачи переезжают на завтра

### Таймер

- Два режима: помидоро с автозавершением и свободный секундомер
- Круговой циферблат в шапке, окрашен в цвет активной задачи
- Пауза и продолжение — кнопкой или пробелом
- **⏹ Стоп** — время засчитывается, задача помечается «частично»
- **✓ Готово** — время засчитывается, задача закрывается
- Прерванные сессии сохраняются с флагом `completed: false` — время потрачено
- Настройки длительности фокуса и перерыва в поповере ⚙

### Уведомления о конце помидорки

Сигнал не пропадает сам и рассчитан на работу в фоне:

- Модальное окно, которое ждёт действия (Enter / Esc / клик)
- Звуковой сигнал через WebAudio, повторяется, пока вкладка скрыта
- Мигание заголовка вкладки — видно из другой вкладки
- Системное уведомление с `requireInteraction`, клик возвращает в приложение

Кнопка разрешения показывает текущее состояние: «Разрешить», «Разрешены»,
«Заблокированы» или «Недоступны». Есть кнопка «Проверить» — показывает
уведомление сразу, без ожидания таймера.

### Календарь и статистика

- Календарь по клику на дату: дни с работой подсвечены, точка отмечает сессии,
  жирным — дни с задачами
- Один график: часы по дням, столбик разбит на сегменты по задачам
- Периоды: неделя, месяц, год (за год данные группируются по месяцам)
- Автоматический масштаб: пока времени мало, ось в минутах, дальше в часах
- KPI: всего, среднее за активный день, число активных дней

### Интерфейс

- Тёмная и светлая темы, выбор запоминается
- Собственный набор SVG-иконок, без эмодзи
- Календарь и настройки — всплывающие панели, не сдвигают содержимое
- Учитывается `prefers-reduced-motion`, адаптив для узких экранов

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка статики: `npm run build` → папка `dist/`, раздаётся любым хостингом
(GitHub Pages, Netlify, Vercel) или локально через `npm run preview`.

## Структура

```
src/
  lib/
    types.ts      доменная модель: Task, Session, Category, Settings,
                  статусы, палитра задач
    storage.ts    слой хранения (localStorage), стартовый набор задач
    useStore.ts   состояние приложения, логика таймера, цвета задач
    icons.tsx     набор SVG-иконок и индикаторы статусов
  screens/
    Today.tsx     главный экран: дата, таймер, прогресс, задачи, статистика
    Stats.tsx     график часов по дням (встраивается в Today)
    Calendar.tsx  месячная сетка с подсветкой рабочих дней
  App.tsx         корень: темы, тосты, модалка уведомления, горячие клавиши
  styles.css      дизайн-система на CSS-переменных
```

Ключевые решения:

- **Источник правды по времени — сессии.** Поле `spent` нигде не хранится,
  всегда считается из `Session`. Поэтому статистика не может разойтись
  с реальностью.
- **Хранение изолировано в `storage.ts`** — при переезде на бэкенд или SQLite
  меняется только этот файл.
- **Цвет задачи — по её порядковому номеру внутри дня**, а не по хешу id:
  хеш давал совпадения уже на четвёртой задаче.
- **Ручная отметка «выполнено» дописывает время до планового**, иначе задача
  была бы зелёной, но невидимой для статистики.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | пауза / продолжение таймера |
| `Enter` | сохранить правку задачи; закрыть уведомление |
| `Esc` | отменить правку; закрыть календарь, настройки, уведомление |

## Данные

Всё хранится в `localStorage` под ключом `tracker-dayplan-v1`. При первом
запуске создаётся пять примерных задач на сегодня, история пустая — график
заполняется только реальной работой.

Кнопка сброса — внизу блока статистики.

> Ограничение: данные живут в одном браузере. Очистка кэша их удалит,
> на другом устройстве их не будет. Экспорт/импорт JSON — в планах.
